Inthegame (Synced Apps Technologies Ltd.) is a viewer-interaction and CTV/OTT engagement platform. Its patented no-code layer injects interactive in-stream overlays — polls, trivia, ratings, wikis, offers and a points shop — into live and recorded video across smart TVs and mobile devices, driving engagement and monetization for streaming platforms and broadcasters. The API exposes two surfaces: an adminApi for broadcasters to manage streamers/channels and inject engagements, and a userApi for end-viewers to register, play, answer, chat, buy and climb real-time leaderboards, with a Socket.IO channel pushing live engagement events.

**Areas:** Company · Streaming · CTV · OTT · Video · Engagement · Interactive · Gamification · Sports · Real-Time

## How this profile is made
